# 🚀 UniDownloader — Modern Media Downloader

Современный веб-сервис для скачивания видео, аудио, субтитров, Shorts и плейлистов с YouTube, TikTok, VK, Instagram, Twitter/X, Rutube, Vimeo, SoundCloud и более 1000+ других сервисов в максимальном качестве.

---

## ✨ Основные возможности

- 🎬 **Видео в любом разрешении**: 4K UHD (2160p), 2K (1440p), Full HD 1080p 60fps, 720p HD, 480p, 360p (MP4, MKV, WebM) с выбором кодеков (H.264 / AV1 / VP9).
- 🎵 **Извлечение аудио**: MP3 (320 kbps High Quality, 256 kbps, 192 kbps), M4A (AAC для iPhone), FLAC Lossless, WAV, OPUS с автоматическим сохранением обложки и ID3-тегов.
- 💬 **Субтитры**: Скачивание субтитров на любых языках (ручные и автогенерация) в форматах SRT, VTT, ASS или вшивание субтитров внутрь видео.
- 📱 **Shorts, Reels и Клипы**: Автоматическое определение коротких видео YouTube Shorts, TikTok (без водяных знаков), Instagram Reels, VK Клипов.
- 📂 **Плейлисты и Каналы**: Удобный просмотр всех видео плейлиста, фильтрация по названию, выбор нужных роликов и пакетное скачивание в 1 клик.
- 🍪 **Поддержка Cookies (с куками и без кук)**:
  - 1 клик — автоматическое извлечение сессии из браузера (**Chrome, Edge, Firefox, Brave, Opera, Vivaldi**).
  - Загрузка файла `cookies.txt` (Netscape формат).
  - Прямая вставка текста cookies.
  - Позволяет скачивать видео с ограничением 18+, приватные ролики и контент для спонсоров/подписчиков.
- ⚡ **Живой прогресс**: Отображение процентов, скорости (МБ/с), оставшегося времени (ETA) и статуса объединения FFmpeg в реальном времени через WebSockets.
- 🎧 **Встроенный медиаплеер**: Воспроизведение скачанных видео и аудио прямо в браузере.
- 🌐 **Пакетная загрузка (Batch)**: Вставка списка ссылок и скачивание пачкой.
- ⚙️ **Прокси (HTTP/SOCKS5)** для обхода региональных блокировок.

## 🚀 Быстрый запуск на Windows

1. Дважды кликните по файлу **`start.bat`**.
2. Браузер автоматически откроется по адресу [http://localhost:8000](http://localhost:8000).

Или вручную через терминал:
```bash
# Активация виртуального окружения
.venv\Scripts\activate

# Запуск сервера
uvicorn backend.app:app --host 0.0.0.0 --port 8000 --reload
```

## 🍪 Как использовать Cookies для 18+ и закрытых видео

1. Нажмите на кнопку **«Куки & Доступ»** в шапке сайта.
2. **Вариант А (самый простой)**: Нажмите на кнопку вашего браузера (например, *Google Chrome* или *Edge*), где вы уже залогинены в аккаунт.
3. **Вариант Б**: Установите расширение для браузера `Get cookies.txt LOCALLY`, экспортируйте `cookies.txt` и перетащите его в окно UniDownloader.
4. Отметьте галочку **«Использовать Cookies»** под строкой поиска.
